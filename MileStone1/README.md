#Supply Chain Visibility and Optimization
1. Objective
-> To import the supply chain dataset into Power BI, clean and transform the data using Power Query, and design a star schema data model for efficient business analysis.

2. Data Source
-> Supply Chain Dataset provided for the Infosys Springboard project in CSV format.

3. Data cleaning and Transforming Steps
-> Imported the CSV dataset into Power BI.
-> Checked and handled missing values.
-> Removed duplicate records.
-> Corrected data types.
-> Renamed columns where required.
-> Applied necessary transformations using Power Query.
-> Created fact and dimension tables.

4. Data Model View
-> A star schema data model was created with one fact table and multiple dimension tables. Relationships were defined using primary and foreign keys to support efficient reporting and analysis.

5. Tools used
-> Power BI Desktop
-> Power Query
-> Git Hub
